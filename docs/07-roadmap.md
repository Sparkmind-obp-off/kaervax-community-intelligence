# Roadmap

## Phase 0 — Foundation
Repository documentation, architecture, data model, security baseline, adapter contract and scoring model.

## Phase 1 — Community Radar
Community registry, manual onboarding, dashboard, tags/categories, activity and opportunity indicators.

## Phase 2 — Intelligence Inbox
Ingestion, normalization/dedupe, topic and intent extraction, demand extraction and source evidence.

## Phase 3 — Opportunity Engine
Scoring, qualification workflow, opportunity database, follow-up states and notifications.

## Phase 4 — Connector Expansion
Threads, Reddit, X, Meta permitted surfaces, Telegram/Discord and manual fallback.

## Phase 5 — Action Center
Reply drafting, offer drafting, human approval, supported API publishing and audit trail.

## Phase 6 — Kaervax integration
Community Intelligence → Kaervax Opportunity Database → Offer/Delivery systems → revenue tracking.

## Definition of done
A user can add communities, ingest content, see meaningful demand, inspect evidence, approve a next action and track the result without manually opening every platform.
