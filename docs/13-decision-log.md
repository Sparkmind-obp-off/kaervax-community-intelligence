# Decision Log

## D001 — Kaervax infrastructure
Community Intelligence is an internal Kaervax capability first, not a separate brand.

## D002 — API optional
The product must remain useful if one platform API is unavailable, restricted or costly.

## D003 — Human approval
External engagement starts human-in-the-loop to reduce accidental spam, policy violations and bad AI interpretations.

## D004 — Opportunity is the business unit
Community count is an operational metric. Qualified opportunities and outcomes are business metrics.

## D005 — Evidence required
Every opportunity retains source provenance so the operator can verify context before acting.

## D006 — Adapter isolation
Platform-specific behavior stays outside the core intelligence pipeline.
